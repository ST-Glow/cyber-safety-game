# 原生 2.5D 课堂游戏

本目录实现独立的 HTML / CSS / ES modules / Canvas 2D 客户端。运行与构建不需要 Godot、Three.js 或 WebAssembly。旧版源代码、资源、构建工具及 `/classroom/game/` 入口继续保留。

## 构建与旧版保护

从仓库根目录运行 `node classroom-web/tools/build.mjs`。

构建以已经确认的 `dist/classroom-preview-site` 为基线，先核对正确的预览项目编号，再复制到全新的 `dist/classroom-native-site-时间戳`，只增加 `/classroom/native/`。不调用旧版 Godot 导出工具。构建对旧入口及公共资源逐个核对 SHA-256，仅允许新增原生资源、新缓存规则和老师记录页的版本标记。报告保存在 `tmp/native/latest-build.json`；原基线目录不改动。

新素材使用内容哈希文件名。模块及入口重新验证缓存；不发布测试、开发服务器、数据库、账号凭据或导出工具。构建以完整新目录作为首屏大小的保守上限，强制检查首屏 5 MB / 总计 15 MB。第一阶段约 1.27 MB，均按未压缩文件大小计，旧引擎文件不计入且不会被新版引用。

`node classroom-web/tools/verify-published-legacy.mjs` 读取最新构建报告，对当前预览站逐个下载旧文件核对哈希。需要能访问现有 Vercel 域名。部署必须在报告指定的新构建目录进行，不能在仓库根目录调用 Vercel 部署，因为根目录绑定的是其他项目。
