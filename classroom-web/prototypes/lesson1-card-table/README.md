## 学生入口与记录

- 每次打开页面先选择班级、填写姓名。线上实验由服务器限制为初一1班、6班；本地普通试玩和历史上传入口保留1—16班。已有存档依赖稳定的 `class_id`，请勿随意修改编号。
- 首次登记和导览不计入主线倒计时。已有进度的学生填写相同班级、姓名后，恢复这台电脑当前浏览器中的进度；匹配检查点也可恢复。
- 菜单中的“更换学生”会保存当前进度并清空登记表。班级不同或姓名不同，进度和手动备份分别保存；不会继承旧版未署名的存档。
- “重新开始”创建新的 `run_id`，保留之前的本机记录。菜单“导出过程记录”导出当前一局 JSON，包括 `state.participant` 中的班级、姓名、试玩版本，以及行动、匹配尝试等事件。实验时应及时导出并收集文件。
- 本地开发默认只保存本机记录；云端发布包启用第1课专用上传模式。云端模式在登记后说明录制用途，由学生授权共享当前游戏标签页，记录操作、结果和录像，并在结束时核验上传到私有 OSS。同班同名在同一浏览器中仍会视为同一位学生；本版不验证身份，也不支持跨电脑自动恢复进度。
- 本机键以 `candy-card-game:g7-l01:student-v1` 开头，按班级和姓名分隔；`session` 保存最新进度，`backup` 保存手动备份，`run:<run_id>` 保存各局记录。旧局目前保存在浏览器中，菜单导出只针对当前局。

## 游戏流程与视觉

操作顺序为“选择行动卡 → 点击场景对象 → 查看反馈”。五张行动卡都可以尝试，错误行动给出反馈。三关分别观察中央计算机单点故障、协议不一致和备用路径；完成后展示成果展板。

首次开始提供欢迎页和五步聚光导览，菜单可以重看。每关结束提供两组知识匹配：拖动概念卡到解释卡，也可点击配对；支持跳过和 Escape。匹配全部完成后3秒自动继续，也可立即继续。导览和匹配期间暂停主线倒计时。

保留校园地图及场景素材，第1课使用专用暖色纸牌框、图标和覆盖样式。学生入口模块及样式仅由第1课引入，不改变第4课的牌框、登录方式或游戏逻辑。
